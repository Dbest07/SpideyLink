# SpideyLink

## Downloads

Public releases provide **only the executable** (`SpideyLink.exe`).

The full source is not included in public release assets or the main branch. Corresponding source for AGPL compliance is available in the private development repository or on request to authorized collaborators.

See the latest release for the current Windows build.
