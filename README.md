## Updates

The app checks for updates in the background and applies verified updates the next time it is opened. No separate updater download is required — just run `SpideyLink.exe`. You can also use the “Check for updates” button in the app.

## UI updates (preview)

Recent UI changes make the main window cleaner and more professional (AnyDesk-inspired layout, spider theme retained, collaborator/encrypted-files panel removed from the main view, updates card kept). Apply the updated `index.tis` and `index.css` from the private development tree before the next build.
